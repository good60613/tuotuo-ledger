# 雲端備份設定（PK 要在 Google 那邊做的事）

程式已經寫好（web-cloud-backup 分支），但還缺兩組 Google 給的「用戶端」，雲端備份才會動。
下面要用你的 Google 帳號登入 Google Cloud 操作，Claude 不能代你登入。

> 名詞：**用戶端 ID**＝Google 用來認出「這是拖拖記帳」的一串公開號碼，不是密碼，放進程式裡沒關係。

## 一、建專案、開 Drive API

1. 到 https://console.cloud.google.com/ ，左上角專案選單 →〔新增專案〕，名稱填 `tuotuo-ledger`。
   （建議另開，不要跟打卡鐘共用，之後正式上架才不會互相影響。）
2. 上方搜尋「Google Drive API」→〔啟用〕。

## 二、同意畫面（使用者登入時看到的那頁）

左邊選單「Google Auth Platform」：

1. **品牌（Branding）**
   - App 名稱：拖拖記帳
   - 使用者支援電子郵件：你的 Gmail
   - App 首頁：`https://good60613.github.io/tuotuo-ledger/`
   - 隱私權政策：`https://good60613.github.io/tuotuo-ledger/privacy.html`
   - 已授權網域：`good60613.github.io`
   - **先不要上傳 logo**：有 logo 就要多一道品牌審查，等之後上架 Google Play 再補。
2. **目標對象（Audience）**：選「外部」。
3. **資料存取（Data access）**：〔新增或移除範圍〕→ 找 `.../auth/drive.appdata` 打勾。
   這是 Google 歸在「非敏感」的權限，所以不用送安全審查。

## 三、兩組用戶端（Clients）

### 網頁版
〔建立用戶端〕→ 類型「網頁應用程式」：
- 已授權的 JavaScript 來源：
  - `https://good60613.github.io`
  - `http://localhost:5173`（Claude 在電腦上測試用）
- 建好後把**用戶端 ID**（`…apps.googleusercontent.com` 結尾）貼給 Claude，會填進 `src/config.ts` 的 `CLOUD.webClientId`。

### APK 版
〔建立用戶端〕→ 類型「Android」：
- 套件名稱：`tw.pk.ledger`
- SHA-1 憑證指紋：APK 簽章金鑰的指紋。在 PowerShell 跑下面這行（路徑換成你的金鑰檔，會問金鑰密碼）：

  ```powershell
  & "D:\1\jbr\bin\keytool.exe" -list -v -keystore "你的金鑰檔.jks"
  ```

  把輸出裡 `SHA1:` 後面那串貼上去。APK 版不用把 ID 給 Claude，Google 靠指紋認。

## 四、發布成正式版

「目標對象」頁 →〔發布應用程式〕。發布後任何 Gmail 都能登入，不用名單。
- 只用非敏感權限，正常情況下不必等審查；Google 若要求驗證網域，照它的指示在 Search Console 驗證 `good60613.github.io`。
- 萬一 Google 不接受 github.io 網域，就要買一個自己的網域（一年約 300～500 元），到時 Claude 再幫你換。

## 五、網站上線

1. GitHub 倉庫 → Settings → Pages → Source 選「GitHub Actions」。
2. 分支合併到 main 後會自動上線（流程：`.github/workflows/deploy-web.yml`）。
3. 朋友用 iPhone 的 **Safari** 打開網址 → 分享 →「加入主畫面」→ 之後都從主畫面的圖示打開。
