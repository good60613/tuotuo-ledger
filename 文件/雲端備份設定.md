# 雲端備份與網站上線設定（PK 要做的事）

網址：**https://toto.pkzio.com**　　公開聯絡信箱：**support@pkzio.com**（轉寄到你的 Gmail）

程式已經寫好（web-cloud-backup 分支）。下面這些要用你的帳號登入操作，Claude 不能代你登入。
照順序做就好，每一步做完打勾。

---

## 一、Cloudflare：把網址指到 GitHub（約 2 分鐘）

1. 登入 Cloudflare → 點 `pkzio.com` → 左邊「DNS」→「Records」→〔Add record〕
2. 填：
   - Type：`CNAME`
   - Name：`toto`
   - Target：`good60613.github.io`
   - Proxy status：**點成灰色雲朵（DNS only）**。橘色會讓 GitHub 發不了加密憑證
3. 〔Save〕

## 二、GitHub：告訴它這個網址要顯示拖拖記帳（約 2 分鐘）

1. 打開 https://github.com/good60613/tuotuo-ledger → 上方〔Settings〕→ 左邊〔Pages〕
2. Source：選「GitHub Actions」
3. Custom domain：填 `toto.pkzio.com` →〔Save〕
4. 等它檢查通過（幾分鐘），把〔Enforce HTTPS〕打勾

> 網站要等分支合併到 main 後才會真的上線。上面這些可以先設好。

## 三、Cloudflare：開信箱轉寄（約 3 分鐘）

> 如果 `pkzio.com` 現在已經有在收信（例如已經有別的網域信箱），先跟 Claude 說，不要做這步。

1. Cloudflare → `pkzio.com` → 左邊「Email」→「Email Routing」→ 啟用（它會自動幫你加好需要的設定）
2. 〔Destination addresses〕加你的 Gmail → 去 Gmail 收驗證信、點確認
3. 〔Routing rules〕→〔Create address〕：Custom address 填 `support`，動作選寄到你的 Gmail
4. 用別的信箱寄一封信到 `support@pkzio.com` 試試看，Gmail 收得到就完成

## 四、Google Cloud：建專案與同意畫面（約 10 分鐘）

1. 到 https://console.cloud.google.com/ ，左上角專案選單 →〔新增專案〕，名稱 `tuotuo-ledger`
2. 上方搜尋「Google Drive API」→〔啟用〕
3. 左邊選單「Google Auth Platform」：
   - **品牌（Branding）**
     - App 名稱：拖拖記帳
     - 使用者支援電子郵件：選你的 Gmail（這格只能選 Google 帳號）
     - App 首頁：`https://toto.pkzio.com/`
     - 隱私權政策：`https://toto.pkzio.com/privacy.html`
     - 已授權網域：`pkzio.com`
     - 開發人員聯絡資訊：`support@pkzio.com`
     - **先不要上傳 logo**：上傳了就要多一道審查
   - **目標對象（Audience）**：外部
   - **資料存取（Data access）**：〔新增或移除範圍〕→ 勾 `.../auth/drive.appdata`
4. Google 要你驗證網域時：到 Search Console 新增「網域」類型的資源 `pkzio.com`。它會給一串 TXT 文字，
   到 Cloudflare 的 DNS 新增一筆 `TXT`，Name 填 `@`，內容貼那串。Search Console 也可能直接提供「用 Cloudflare 自動驗證」的按鈕，用那個更快。

## 五、Google Cloud：兩組用戶端（約 5 分鐘）

「Google Auth Platform」→「用戶端（Clients）」→〔建立用戶端〕：

**網頁版**：類型「網頁應用程式」
- 已授權的 JavaScript 來源：`https://toto.pkzio.com`、`http://localhost:5173`（後面這個是 Claude 在電腦上測試用）
- 建好後把**用戶端 ID**（`…apps.googleusercontent.com` 結尾）貼給 Claude

**APK 版**：類型「Android」
- 套件名稱：`tw.pk.ledger`
- SHA-1 憑證指紋：在 PowerShell 跑下面這行（路徑換成你的金鑰檔，會問金鑰密碼），把 `SHA1:` 後面那串貼上去

  ```powershell
  & "D:\1\jbr\bin\keytool.exe" -list -v -keystore "你的金鑰檔.jks"
  ```

## 六、發布

「目標對象」頁 →〔發布應用程式〕→ 正式版，任何 Gmail 都能登入。
只用「非敏感」權限，正常不用等審查。
