# 拖拖記帳 更新紀錄

## 2.0.1（versionCode 10，2026-11-10）2.0 補強批：朋友付改算法＋標籤滑動＋定期扣款
資料格式升到 v6（舊備份照常匯入；新版匯出的備份舊版 App 讀不了）。更新前請先匯出備份。

- 朋友付改算法：記帳那天不算支出（帳戶不動、剩餘可用照扣）；還錢那天才算一筆支出。用小帳戶還＝只記在小帳戶，不算主帳，不會重複算。舊資料自動照新規則算，不用轉換。
- 我先付收進小帳戶時，多一行提醒「這筆會留在小帳戶，不會算進主帳支出」（算法不變）。
- 記帳頁膠囊：按住約 0.18 秒才拿起拖曳；沒按住時左右滑就是捲動。點數字再點膠囊照舊。
- 定期扣款（設定 → 定期扣款）：固定金額每月訂閱。新的一期開始時剩餘可用先預留；到扣款日自動記一筆支出；App 沒開時下次打開補記（日期＝原扣款日，不重複）。當月沒有扣款日就在月底扣。開關關掉＝不記、不動帳戶、不預留。

## 2.0（versionCode 9，2026-11-10）2.0 第一批：亮暗色＋拖拖計算機（我先付／朋友付）
資料格式升到 v5（舊備份照常匯入；新版匯出的備份舊版 App 讀不了）。

- 顏色集中在 ：亮色（藍綠清爽，預設）、暗色（金色夕陽）、備用橘黃。設定加「外觀」：亮色／暗色／跟隨系統。
- 首頁剩餘可用：大數字｜分隔線｜右側小字（預算、朋友付）。帳戶卡片左側圖示位（先放首字）。
- 記帳頁：預設選第一個分類；TWD 改成日期（今天／11/09，點了可改日期時間）；上排改成膠囊（帳戶、我先付、朋友付、預算、報帳、其他＝即將推出）。
- 拖拖計算機：把膠囊拖到算式數字上（或點數字再點膠囊）掛標記，OK 前小字預覽「會拆成：吃飯 500＋我先付 600」，按 OK 自動拆成多筆；算式另存，明細看得到。OK 不再先變「＝」，結果即時顯示。
  - 拖到「＋」的數字：一般＝結果－那個數字；拖到「－」後面的數字：一般＝結果。乘除裡的數字不能掛；一般部分變負數不能存；同一標記掛兩個數字＝兩筆。
- 我先付（沿用報帳機制）：當下扣帳戶、不算支出；收回時選錢進哪個帳戶（任何帳戶都可以，含 LINE Pay），不算收入。
- 朋友付：不動帳戶、算本月／今日支出；剩餘可用扣掉未還的；還錢時選從哪個帳戶付（任何帳戶都可以），不再算支出。用悠遊卡、電子錢包還時本月支出會多算一次（儲值時已算過），畫面有提醒。
- 剩餘可用＝一般帳戶加總－未付預算－未還朋友錢。
- 待辦頁分頁：報帳、我先付、朋友付、預算；結案後都能退回。設定加「我先付／朋友付」開關（關掉只是不顯示膠囊，已記的照常計算）。
- 下一批：桌面小工具暗色、毛玻璃、動畫、圖示、「其他」膠囊內容。

## 1.4.1（versionCode 7，2026-11-09）第六批：畫面排列
只改排列，記帳規則、金額計算、資料格式都沒動。

- 首頁由上到下：日期 → 金額區 → 帳戶卡片＋五顆小帳戶球 → 最近紀錄（固定 3 筆，緊靠導覽列）。
- 金額區撐滿剩下的高度，倒三角越下越大：今日收支 → 本月收支 → 剩餘可用（最大）＋已圈預算。字級、間距在 `src/config.ts` 的 `HOME.amount`。
- 長按卡片時，最下面「最近紀錄」那一格換成「支出｜收入」放置區，提示字在放置區上緣；那一格高度固定，拿起時卡片不會移動。長按時間與移動門檻（`GESTURE`）沒改。
- 待辦頁（報帳、預算）與明細頁：筆數少時整串紀錄（含日期標題）貼在底部操作列上方；滿版後照常捲動。順序不變（上新下舊）。
- 悠遊卡、電子錢包等小帳戶畫面這批沒動。
