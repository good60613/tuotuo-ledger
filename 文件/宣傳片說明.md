# 拖拖記帳宣傳片說明

- 成品：`宣傳片輸出/拖拖記帳宣傳片.mp4`，直式 1080×1920、30 秒、30fps，有音效、沒有背景音樂。這個資料夾不進 git。
- 原始碼：`promo/`，和 App 完全分開，有自己的套件。App 的程式和資料都沒有改。
- 工具：Remotion，用寫網頁的方式寫動畫，再一格一格輸出成 MP4。

## 怎麼重新輸出

在 `promo/` 資料夾執行：

```bash
npm install
```

```bash
npm run render
```

- `npm run render` 會先產生音效，再輸出影片，覆蓋舊檔。
- 想邊改邊看：`npm run studio`，會開一個瀏覽器預覽頁，可以拖時間軸。
- 第一次輸出時，Remotion 會自動下載無畫面版 Chrome，大約 100 MB。

## 檔案分工

| 檔案 | 內容 |
|---|---|
| `promo/src/Promo.tsx` | 分鏡起點 `S`、字幕、音效排程 `CUES`、開場和結尾。想改節奏先看這裡。 |
| `promo/src/screens.tsx` | 手機裡的五個畫面：首頁、小帳戶球、待辦、桌面小工具、統計，以及各自的動作時間點 |
| `promo/src/parts.tsx` | 共用零件：向量金幣（普通臉、笑臉）、手指、手機框、字幕、背景、動畫小工具 |
| `promo/scripts/make-sfx.mjs` | 用數學算出聲波來產生音效，輸出到 `promo/public/sfx/`，不用任何外部音檔 |
| `promo/public/icon.png` | 從專案根目錄的 `icon.png` 複製過來 |

## 常見修改

- **改字幕文字**：`Promo.tsx` 裡的 `<Subtitle ... text="..." />`。
- **改某段的長短**：調 `Promo.tsx` 的 `S`。那段裡面的動作時間在 `screens.tsx` 的 `HOME_T`、`BUDGET_T` 這類常數。
- **改音量或換音效**：`CUES` 每一列的格式是 `[格數, 音效名稱, 音量]`。
- **改音色**：改 `make-sfx.mjs` 裡對應的公式，再跑一次 `npm run render`。
- **改假資料**：金額直接寫在 `screens.tsx` 裡。首頁、小工具、統計三個畫面的數字要一起對：記帳後今日支出 120、本月支出 18,640、剩餘可用 62,260。

## 已知限制

- `icon.png` 是一整張圖，背景、手指和哭臉畫在一起，拆不開。所以只有開場「被捏」那一下用原圖，其他時候是照原圖用程式重畫的向量金幣。之後如果要每個表情都是原畫風格，需要另外提供去背的各表情圖。
- 字型用 Windows 內建的微軟正黑體，表情符號用 Windows 的樣式。換一台電腦輸出，字型和表情符號的樣子可能會不一樣。

## 3.0 真機錄影剪輯（`promo/src/Cuts.tsx`）

- 素材：PK 的真機錄影放在 `promo/public/rec.mp4`（不進 git），片頭片尾 `intro.mp4`、`outro.mp4` 是從上面那支宣傳片切出來的 3 秒。
- `Cuts`：五段（記帳、轉帳、剩餘可用、匯入、教學），裁掉狀態列、跳過鍵盤（鍵盤背景是個人照片）、分享選單的聯絡人那一排模糊。剪接秒數在 `SEGS`。
- `Draft`：片頭＋五段＋片尾的初剪，沒有配音（PK 在剪映加）。
- 輸出位置：`宣傳片輸出/3.0素材/`。各段用 `--frames` 從 `Cuts` 切出來。
