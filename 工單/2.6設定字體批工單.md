## A. 首頁「平均 ××× / 日」（使用問題）

- **位置（截圖 1）**：首頁最上面大卡片，**「剩餘可用 $4,957」與右邊「預算 $1,568」之間的空位**（PK 用綠框框起來的地方）。
- 顯示：「平均 $XXX / 日」。
- 算法：**剩餘可用 ÷ 離結算日還有幾天 ＝ 金額，四捨五入到整數。**
  - 「剩餘可用」沿用首頁現在顯示的那個數字，**不要另寫一套算法**。
  - 結算日目前設定「每月 5 號」。結算日當天或已過：天數最少當 1，避免除以 0。
  - **剩餘可用是負數時：照樣顯示負數**（PK 已決定），例如「平均 -$120 / 日」，顏色沿用現有負數的紅色。
  - 「離結算日還有幾天」是否含今天，先看現有首頁怎麼算，**跟它一致**，回報即可。
- **設定裡加開關**（預設關閉，PK 再決定要不要預設開）。關閉時這個空位完全不出現。
- 位置窄：請確認金額很大（例如 $12,345）、負數或字體換大時，三塊不會擠在一起或被切掉。

## B. 設定頁依分類整理（使用問題）

**現況（截圖 2、3）**：設定頁是一條很長的列表，混著外觀、記帳、圖示、通知、帳戶管理、結算日…。

- 依用途分類。**分法交給 Claude Code 提案（PK 已授權，參考下面的建議即可，不需再等 PK 逐項定）**。**現有的每一項設定都要保留、全部放進去，不要漏。**
- **建議分法（可微調）**：
  1. **外觀**：外觀（亮色／暗色／跟隨系統）、毛玻璃、字體（見 C 段）
  2. **圖示**：首頁小語圖示、桌面小工具圖示、手機桌面 App 圖示
  3. **記帳**：記帳預設帳戶、預設報帳帳戶、明細顯示記帳前餘額、先付／先欠、定期扣款、結算日、首頁使用（帳戶頁／明細頁）、平均／日（A 段新開關）
  4. **通知與隱私**：通知欄快捷列、鎖定畫面隱藏金額
  5. **管理**：帳戶管理、小帳戶管理、分類管理、備註標籤、手機條碼載具
- 選項能做成**按鈕框**就做成按鈕框。**範例就是截圖 2 的「外觀：亮色／暗色／跟隨系統」**。選項太長或不適合就用**兩層選單**或**彈窗選擇**。
  - 適合按鈕框（選項短、數量少）：外觀、記帳預設帳戶、首頁使用、各種開／關。
  - 適合進下一層：帳戶管理、小帳戶管理、分類管理、備註標籤、預設報帳帳戶、結算日等（現在本來就是右邊有「›」，保持即可）。
- **圖示修改（截圖 2 藍框內三區）改成兩層選單。**
  - 第一層：只顯示三個項目＋目前選擇（例如「跟著心情換」「原版」）。
  - 第二層：點進去才顯示那一排圖示，選好返回。
  - **第一顆按鈕「自動」**（前兩區才有）：它是「跟著心情換」的實際功能，**不能取消**。Claude 的決定：**讓它跟旁邊圖示一樣是填滿的色塊，只用金色外框標示選中**，不再是空心框。第三區（手機桌面 App 圖示）沒有「自動」，第一顆就是普通圖示。
  - 「換了之後，有些手機會把桌面上的舊圖示拿掉…」那段提示保留，但放進第二層、字縮短。
- **文字精簡（太冗長，兩行擠在一起）**：
  - 毛玻璃效果：「開啟（手機卡頓時可關閉）」→ 改成名稱「毛玻璃」＋開關，說明縮成一行小字，意思是 **（提升手機性能）（增加視覺效果）**，由 Code 寫成通順的一句，列在回報讓 PK 看。
  - 通知欄快捷列：**只留名稱和開關，說明文字拿掉。**
  - 鎖定畫面隱藏金額：同樣縮短，只留名稱和開關。
  - 其他太長的敘述順手縮短，列在回報裡。

## 驗收（PK 用手機）

1. 設定打開「平均／日」，首頁綠框位置出現數字。例：今天 11/21，結算日 12/5，還有 14 天，剩餘 $4,957 ÷ 14 ＝ $354。關掉就消失。剩餘為負時顯示負數。
2. 結算日當天不會當機、不會顯示怪數字；金額很大也不擠。
3. 設定頁有分類，原本每一項都找得到，沒有漏。
4. 圖示修改是兩層選單，「自動」那顆是填滿色塊、功能正常。
5. 毛玻璃、通知欄快捷列、鎖定畫面隱藏金額的敘述已精簡。
6. 換字體後各頁面不跑版；選「跟隨系統」會回到手機原本字體。
7. 餘額、本月與今日數字跟改之前一致。
