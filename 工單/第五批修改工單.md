## 一、各段工作

### A 段：共用「底部操作列」元件
- 做一個固定在底部導覽列正上方的操作列，不跟著頁面捲動。統計、明細共用。
- 頁面內容的底部要留空，避免最後一筆被操作列蓋住。
- 高度、間距放 `src/config.ts`。

### B 段：統計頁
- 底部操作列放：**全部帳戶｜月份切換｜「本月」按鈕**（「本月」原本在右上角，一起搬下來）。
- 上方保留：標題與「今天 11/8」、本期支出／收入、本期預算（都是只看的）。
- 其餘內容（圓環圖、分類列表）不動。

### C 段：明細頁
- 底部操作列放：**全部帳戶｜月份切換**（與統計共用元件，兩頁一起改）。
- 本期支出／收入卡片、**五顆小帳戶球維持在上方不動**（PK 決定：球在明細頁少用，先觀察）。
- 右下角「＋」要浮在新的操作列上方，不可重疊。

### D 段：待辦頁（由下往上，離拇指最近的最先）
1. 「報帳／預算」切換：貼在導覽列正上方（最大、最常切換）。
2. 「未付／已付」：往上一層。
3. 「多選」按鈕與「點一筆看詳細；長按可多選」提示字：再往上。
4. 「未付預算總額」：只是看的，放最上面。
- 進入多選時，底部的批次操作列**取代**切換列的位置，不要疊在一起；退出多選時還原。
- 報帳分頁比照預算分頁的排法。

### E 段：首頁（由上到下）
1. 最上：剩餘可用、已圈預算、本月收入／支出、今日收入／支出（只看的）。
2. 中間：最近紀錄（筆數依剩餘空間決定，放不下則隱藏，規則不變）。
3. 最下：**帳戶卡片（上）→ 五顆小帳戶球（下）**，貼近底部導覽列。
- 長按卡片時出現的支出／收入放置區：請 Code 先回報目前是取代哪一塊，並維持「放置區離卡片很近、好拖到」的效果。
- 卡片區（最多 3 排／6 張，超過可區內捲動）移到下方後，**長按拖曳與捲動的區分要重測**，需 PK 手機實測。

### F 段：盤點其他畫面（只列清單，不改）
- 請 Code 列出：哪些畫面有「按鈕或控制項在上面」（例如記帳頁、設定各子頁、帳戶管理、分類管理、備註管理、各小帳戶畫面）。
- 每個畫面用白話寫：現在在哪、搬下來會不會有問題。
- **由 PK 挑要改哪幾個**，PK 沒點頭前不改。

### G 段：檢查與打包

## 二、可能出事（Code 要特別檢查）

- 明細的「＋」與底部操作列重疊。
- 待辦多選的批次操作列與切換列疊在一起。

- 內容被固定的底部列蓋住，最後一筆看不到。
- 小螢幕（高度較矮的手機）上，底部列加導覽列佔掉太多空間。
