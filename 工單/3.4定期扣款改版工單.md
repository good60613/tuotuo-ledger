# 3.4 定期扣款改版工單（2026-11-22，先做後補）

分支：todo-recurring。versionCode 23／3.4.0。資料格式不變（v7）。

## PK 定案
1. 入口：待辦頁下方切換列加「扣款」，放正中間：報帳／先付／扣款／先欠／預算。不做左右滑（待辦頁左右滑＝換頁，會搶手勢）、不加第二排。設定裡的入口保留；首頁「定期扣款」小字改跳待辦頁扣款分頁。
2. 週期：每週（星期幾）／每月（幾號）／每年（幾月幾號）。
3. 預留：每年＝扣款日落在哪期，那期一開始整筆預留；每週＝這期還沒扣的每一次都預留。
4. 清單上方「本月合計」：只算這一期。偶爾遇到每年扣款那個月變多，屬合理。
5. 在哪取消：應用商城／App 內／網頁／其他（可不填）；其他備註：自由文字（例如取消網址）。
6. 自動記帳時間：扣款日過完、隔天才記，時間寫扣款日 23:59。
7. 說明文字：「固定金額的週期性訂閱，可選每週／每月／每年。新的一期開始時，剩餘可用會先預留這期要扣的錢；扣款日過完，隔天自動記一筆支出（記在扣款日 23:59）。」細節（補記、月底）搬到說明頁。

## 做法重點
- 每一次扣款用 key 代表：每月 'YYYY-MM'、每年 'YYYY'、每週那天 'YYYY-MM-DD'；沿用 nextMonth、recurringMonth 欄位，舊資料不用升版。
- 已扣過再換週期（或每週改星期幾）：從原本下一次扣款日起算，已付那段不重複扣；沒扣過＝從今天起算。每月→每月、每年→每年改日期維持原規則。
- 匯入舊設定檔：週期不同時比扣款日（laterNext），不讓已扣過的再扣。
- 刪除：已記的支出保留，只有這期還沒扣的預留放回剩餘可用。
