# 拖拖記帳 2.0 第一批工單：亮暗色＋拖拖計算機（代墊／借我）

日期：2026-11-09｜決定者：PK｜整理：Claude（Chat）

本批範圍：一、配色與亮暗色模式；二、記帳頁預設分類；三、拖拖計算機（膠囊按鈕、拖到數字自動拆帳）；四、代墊與借我兩個新標記；五、開關。
不在本批：毛玻璃（Liquid Glass）、光影、動畫、分類與帳戶圖示重新設計、「其他」膠囊內容。這些下一張工單再做。

建議施工順序：先做配色與亮暗色（只換顏色），再做功能。功能的膠囊直接用新顏色。

## 一、配色與亮暗色模式

分類：構造或架構問題（全 App 顏色要集中成一套「顏色清單」）

- 把整個 App 用到的顏色整理成一套顏色清單（例如背景、卡片、文字、次要文字、支出紅、收入綠、主色、框線），集中在一個設定檔；亮色、暗色各一份。之後的毛玻璃與圖示都建在這套清單上。
- 設定裡三個選項：亮色／暗色／跟隨系統。預設：亮色。
- 亮色：藍綠清爽風。白底，天空藍與薄荷綠點綴，清晰溫柔。
- 暗色：金色夕陽風。深炭灰底，邊緣與重點帶微微金色光，沉穩有質感。
- 橘黃溫暖風（奶油白底、橘與金黃點綴）：本批先把色票寫進清單備用，不用做切換介面；之後做「自訂主題」時當可選主題。
- 剩餘可用的顯示方式參考 PK 提供的模擬圖：大數字旁用分隔線隔開，右側小字顯示「預算 1,000」。本批之後也會在這裡顯示「借我」的金額（見四）。
- 帳戶卡片左側預留圖示位置（圖示本身下一批設計，這批可先用帳戶分類的預設圖示或首字）。卡片的小箭頭先不做。
- 本月收支、今日收支兩行：照新配色先做一版，PK 手機看過再調。
- 只換顏色與上述版面小調，不做毛玻璃與動畫。

## 二、記帳頁預設分類

分類：使用問題

- 進入記帳頁時，「支出」「收入」都預設選中左上第一個分類（框起來）。沒選分類也能直接輸入金額按 OK 記帳。
- 「轉帳」不受影響。

## 三、拖拖計算機

分類：構造或架構問題（新的拖曳互動＋一個算式拆成多筆紀錄）

### 上排改成膠囊按鈕

- 原本「日期｜帳戶｜預算｜報帳」那一排，改成膠囊狀按鈕：帳戶、代墊、借我、預算、報帳、其他。日期不放在膠囊這一排，改放在金額那一排的左邊（見下方「日期欄位」）。
- 「其他」本批只留位置（可先隱藏或顯示「即將推出」，Code 提方案），內容下一批決定。
- 膠囊要跟下方快速標籤明顯不同：快速標籤維持灰色、只有文字、點一下填進備註；拖拖膠囊有顏色與小圖示，用拖的。拖曳開始時，快速標籤那排變淡。最終外觀等下一批改 UI 時再定，這批先做到能分辨即可。

### 拖到算式數字上

- 使用者輸入算式（例如 1100－600），把「代墊」「借我」「預算」「報帳」膠囊拖到算式裡的某個數字上，該數字就掛上那個標記；拖到時數字要亮起來，放置範圍要做大一點。
- 按 OK 時自動拆成多筆紀錄：掛標記的數字各自成為一筆帶標記的紀錄，其餘部分算出結果成為一般紀錄。分類、備註、日期、帳戶相同。
- 例：正餐「吃飯」，1100－600，把代墊拖到 600 → 一筆一般支出 500，一筆代墊 600。帳戶共扣 1,100（當下真的付了 1,100）。
- 備用方法：點一下數字，再點膠囊，效果相同（拖不準時用）。
- 移除標記：在數字上再點一次可取消（Code 提方案）。
- 拖曳的長按時間、移動門檻、放置範圍等數值放在 src/config.ts。

### 算式與備註

- 算式自動存進備註，例如「2000－1000」，讓之後看得出來龍去脈（格式由 Code 提方案，避免與使用者自己打的備註混在一起）。
- 算式與備註欄寬度自動伸縮：只有一個數字時維持一半一半；出現加減乘除時算式撐開、備註縮短；點備註輸入時備註撐開。

### 日期欄位（PK 已定案）

- 金額那一排最左邊原本顯示「TWD」的位置，拿掉 TWD，改顯示日期。今天顯示「今天」，其他天顯示「11/09」這樣的短格式。
- 時間不用特別顯示在這一格。
- 點一下日期，跳出選擇視窗，可以改日期，也可以改時間。
- 預設日期與時間是進入記帳頁的當下。
- 金額、備註、日期這一排的寬度怎麼分配，Code 提方案；原則是算式優先，因為拖拖膠囊要拖到數字上，數字不能太擠。

### 需要 Code 提出的疑問

- 一個數字上能不能掛兩個標記（建議不行，後掛的取代先掛的）。
- 算式有乘除、括號時，掛標記的數字怎麼拆（建議：只允許拖到以加減連接的項目上；或算式含乘除時先不開放，Code 評估後提方案）。
- 拆出來的負數或零（例如掛標記的數字大於總額）怎麼處理。

## 四、代墊與借我

分類：構造或架構問題（碰到錢怎麼算，主對話用 Opus，不派給 implementer）

原則：「支出」看的是什麼時候享受了這個東西；「帳戶」看的是錢實際在哪；「剩餘可用」看的是真正能自由花的錢。

### 代墊（我先幫別人付，之後會收回來；比照報帳）

- 記帳當下：帳戶扣款（使用者選的帳戶）；剩餘可用跟著減少；不計入本月支出、今日支出、分類統計。
- 待辦出現一筆「代墊」等待收回。
- 結案（朋友還錢）：按下時詢問錢進了哪個帳戶，新增一筆入帳紀錄、錢加回該帳戶；不計入收入。原紀錄保留，顯示淺色「已收」。

### 借我（別人先幫我付，之後我要還；類似預算但支出時間不同）

- 記帳當下：不選帳戶、任何帳戶都不動；本月支出、今日支出、分類統計都計入（飯是今天吃的）；剩餘可用減少；剩餘可用旁小字顯示「借我 600」（與「預算 1,000」同一位置、同樣式）。
- 待辦出現一筆「借我」等待還錢。
- 結案（我還錢）：按下時詢問從哪個帳戶付，該帳戶扣款；不再計入任何支出；剩餘可用不再變動（之前已扣過）。原紀錄保留，顯示淺色「已還」。

### 公式

- 剩餘可用＝一般帳戶加總－未付預算－未還借我。
- 代墊與報帳未收回的錢，剩餘可用不先加回，等真的入帳才算（保守）。
- 驗算用例：帳戶加總 14,004、預算 1,000 → 剩餘可用 13,004（現況）；再記一筆借我 600 → 12,404，帳戶加總仍 14,004；還錢 600（從現金）→ 帳戶加總 13,404，剩餘可用仍 12,404。

### 其他

- 待辦頁加入代墊、借我（與報帳、預算並列，分頁或篩選由 Code 提方案）。
- 時間軸／明細比照報帳與預算的標示方式。
- 結案後可「退回」為未結案（比照預算的退回未付）。
- 資料版本升級：舊備份檔仍可匯入；新欄位缺值用預設。

## 五、開關

分類：使用問題

- 設定裡加「代墊／借我」開關，預設開啟。
- 關掉時：計算機上不顯示這兩顆膠囊；但已存在且未結案的代墊、借我，在待辦、剩餘可用、明細中仍照常顯示與計算，避免錢算不清。
- 預留之後改成付費功能的可能（判斷條件集中一處即可），本批不做付費。
