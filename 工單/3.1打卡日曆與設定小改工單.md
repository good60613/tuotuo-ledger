# 3.1 打卡日曆與設定小改（先做後補的工單）

來源：PK 的〈拖拖記帳 3.1 改版〉文件（2026-11-21）。分支 v3.1（從 v3.0 開出），versionCode 21／3.1.0。資料格式不變。

## A 統計頁日曆＝打卡日曆
- 日曆移到統計頁第一塊（在本期支出／收入上面）。只在「月」檢視出現，跟以前一樣。
- 有記帳的日子：日期數字後面墊淡金色實心圓（像蓋章），和「今天」的外框分開。PK 選「圈數字」，不用小勾勾。
- 「有記帳」＝那天（紀錄日期）有任何一筆紀錄；定期扣款自動記的不算。
- 日曆標題右邊：拖拖硬幣（3.1 新圖）＋「連續記帳 N 天」＋一句加油。
  - 今天有記 → 算到今天；今天還沒記 → 先算到昨天（顯示「今天還沒記喔！」），昨天也沒記＝0（「今天記一筆吧！」）。
  - 天數跟正在看哪個月無關，一律算到今天。
  - 句子／圖：1–2 天 加油！（吃飯）、3–6 天 讚讚！繼續保持（交通）、7–13 天 一整週了，讚讚！（撲滿）、14–29 天 超棒的！（購物）、30 天以上 你是記帳達人！（投資）、還沒記 帳單冒汗。
- 程式：src/data/streak.ts、src/pages/Stats.tsx、styles.css（.cal-n.stamp、.streak*）。
