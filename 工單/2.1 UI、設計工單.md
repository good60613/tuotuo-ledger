## 3. 毛玻璃

**只用在這幾樣（會拖、會浮起來的東西）：**

- 底部導航列（浮在畫面下緣的圓角膠囊，高 62，左右各留 14，離底 14）
- 首頁帳戶卡片
- 首頁五顆小帳戶球
- 記帳頁的拖拖膠囊（帳戶、我先付、朋友付、預算、報帳）
- 首頁「剩餘可用」那張大卡

**維持實心、不要毛玻璃：** 明細、統計、設定、計算機按鍵、最近紀錄、所有清單與表單。

**玻璃的做法：** 半透明底（gbg）＋細邊框（gbd）＋陰影（gsh）＋上緣高光（ghi）＋ `backdrop-filter: blur(18px) saturate(160%)`（導航列用 22px／170%）。要同時寫 `-webkit-backdrop-filter`。

**效能保護（重要，PK 的手機是 Android）：**

1. 設定裡加一個開關「毛玻璃效果」，預設開。關掉時，上面那些東西改成實心底（用 solid 與 line），外觀仍一致，只是不透明。
2. 瀏覽器或系統不支援 `backdrop-filter` 時，自動走實心。
3. 背景那幾團彩色光暈（亮色是藍與薄荷、暗色是琥珀與深藍）**不要用「大面積 CSS blur 的元素」做**，那很吃效能。請用 `radial-gradient` 疊成背景，一樣的視覺、便宜很多。（這是 Claude 的建議，你有更好做法可以提。）
4. 同一個畫面上毛玻璃的元素盡量少重疊。首頁最多同時約 4 張卡片＋5 顆球＋1 張大卡＋導航列，請特別量測。
5. 請在報告裡說明你測到什麼、哪裡可能卡。**PK 會用手機實測**，重點是：首頁捲動、長按拖曳卡片、記帳頁拖膠囊，三個動作有沒有掉格。

## 4. 光影與動畫（只做這些，其他不做）

**只在拖曳的瞬間（PK 已決定）：**

- **拿起來**：被拖的東西放大約 1.14 倍、微微傾斜（約 −6 度）、陰影變大、邊緣發出該物件顏色的光（膠囊用自己的顏色，卡片用 acc）。
- **經過目標**：被拖到的目標（記帳頁算式裡的數字、首頁的支出／收入放置區）亮一圈（外框＋淡光暈），離開就熄掉。
- **放下**：輕輕彈一下（回彈，不要誇張）。
- 拖曳開始時，記帳頁的「快速標籤」整排變淡（約 35% 透明度）；結束後恢復。

**規則：** 動畫只用 `transform` 與 `opacity`（不要動 `box-shadow` 大小以外會觸發重排的屬性）；時間與幅度放 `config.ts`；尊重系統的「減少動態效果」設定（開啟時全部關掉，只保留變色）。

**本批不做（PK 還沒決定，請不要加）：** 換頁動畫、記帳成功的動畫、數字變動動畫。

## 5. 圖示系統（這批最大的一塊）

### 5.1 來源與授權
- 圖示庫：**Lucide**（`lucide-static` 1.71.0，ISC 授權，共 2,350 顆）。已確認授權是 ISC，可商用，要保留授權聲明。
- **不要把整個圖示庫打包進 App。** 只收圖示清單裡用到的（約 180 顆），放在一個檔，例如 `src/icons.ts`，並做一個 `<Icon name size />` 元件。
- 顯示規格統一：24 格、`stroke=currentColor`、`stroke-width=1.8`、圓頭圓角、不填色。
- **自繪圖示 7 顆**（手銬 `cuffs`、項圈 `collar`、繩 `rope`、鞭 `whip`、拍板 `paddle`、蠟燭 `candle`、皮帶 `belt`）不在 Lucide 裡，SVG 內層標記寫在圖示清單 JSON 的 `custom` 欄位，直接使用，不要改圖。
- 把 Lucide 的 ISC 授權文字放進專案（例如 `LICENSE-lucide.txt` 或 `THIRD_PARTY_LICENSES.md`），設定頁底部可以加一行「開放原始碼授權」連過去。
- 以後想換別套圖示庫，要只改 `src/icons.ts` 這一處（PK 之前就要求過）。

### 5.2 圖示存的是「名稱」
- 帳戶與分類各存一個 `icon` 欄位，內容是圖示名稱字串（例如 `"utensils"`、`"cuffs"`），**不存 SVG**。
- 這會讓**資料格式升版（第 6 版 → 第 7 版）**，屬 **構造或架構問題**：
  - 新增：帳戶 `icon`（沒填就依帳戶種類給預設，見圖示清單 `accountTypeDefaults`）；分類的 `icon` 欄位從 emoji 改為圖示名稱。
  - **舊紀錄的 emoji 要處理：** 請做一張「emoji → 圖示名稱」對照表，把現有範例與常見 emoji 轉過去。對不到的，**保留原 emoji 照常顯示**，不要丟掉，也不要用「便當」之類的預設代替；使用者之後自己在選單換掉。請把對照表給 PK 看過。
  - **舊備份（第 6 版以下）仍要能匯入**；匯出一律是第 7 版。舊版 App 讀不了第 7 版，這個要在匯出入的提示文字說明一次。
  - 升版前走既有的「自動留底」（資料升級前先留一份）。
  - 備份「只匯出設定」也要帶新欄位。
  - 補測試：第 6 版備份 → 升版 → 帳戶與分類 `icon` 內容正確；第 7 版匯出再匯入完全一致；缺 `icon` 欄位時用預設。

### 5.3 帳戶圖示與「縮寫徽章」
- 帳戶卡片左側加圖示：38 見方、圓角 12、淡底（chip）、圖示 22。
- 帳戶可以選兩種：**圖示**（從圖示清單的帳戶那一組挑）或**縮寫徽章**（取帳戶名稱第一個字，放在彩色圓裡，例如「中」「郵」）。**預設用圖示。** 徽章的顏色用帳戶自己的顏色。
- **不要放真正的銀行 logo。** 銀行 logo 是商標，公開版有風險。以後如果要讓使用者自己選圖片當帳戶圖示，那是另一批，本批不做。

### 5.4 選單
- 分類圖示改成選單，**依圖示清單的分組（飲食、交通、居家、購物、娛樂、醫療健康、學習工作、通訊訂閱、人情家庭、美妝香氛、圈內・BDSM 相關、金融稅務、旅遊戶外、運動、收入、其他）分段顯示**，每段有標題。分類顏色（9 色）選單沿用。
- 帳戶圖示選單用清單的「帳戶」那一組。
- 「圈內・BDSM 相關」是 PK 自己要的分類，**照一般分組處理即可，不用特別標示或隱藏**。
- 本批不做搜尋框、不做「最近用過」。

### 5.5 全部畫面換圖示
- 導航列、膠囊、記帳頁、首頁、明細、統計、待辦、設定、所有選單裡的圖示，**全部改走 `<Icon>`**。App 裡不應該再有手畫 SVG 或當圖示用的 emoji（拖拖膠囊的小圖示、關閉、刪除、新增、日期、更多、退格也是）。
- 底部導航：首頁 `house`、明細 `list`、統計 `chart-column`、待辦 `square-check`、設定 `sliders-horizontal`。**項目名稱與數量以現有 App 為準**（設計稿上的文字是 Claude 猜的），只換圖示與樣式。
- 膠囊小圖示：我先付 `corner-down-left`、朋友付 `corner-down-right`、預算 `target`、報帳 `receipt-text`、更多 `ellipsis`。
