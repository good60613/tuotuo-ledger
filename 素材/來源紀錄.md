記下每一張圖「怎麼來的」：用什麼工具、什麼時候、你做了哪些選擇與修改。日後要說明權利、跟平台或別人溝通時，這份是憑據。

> **提醒**：這個資料夾在公開倉庫裡，任何人都看得到。完整的提示詞若不想公開，這裡只寫工具、日期與你做了什麼，完整提示詞與原始對話另存在自己的電腦或雲端。
> 以下「（請補）」的地方，由 PK 依實際情況填寫，沒有就留空，不要寫不確定的內容。

## 記錄範本

| 欄位 | 填寫說明 |
|---|---|
| 工具與版本 | 例如 GPT 的圖像生成，大約哪個月份 |
| 產生日期 | 大約日期即可 |
| 提示詞摘要 | 你要求的角色、風格、表情、構圖 |
| 挑選 | 一次生成幾張，你選了哪一張，為什麼 |
| 後續編修 | 你自己或用工具做的去背、裁切、調色、修改、組合 |
| 原始檔位置 | 例如 `素材/拖拖硬幣/原圖/…` |
